# QuickNotes System

QuickNotes is a full-scale note-taking web application and system architecture design project capable of scaling to support over one million users. It features a robust front-end client built with vanilla JavaScript, secure asynchronous API communication, and comprehensive technical documentation.

## Project Structure
* `client/` - Front-end HTML, CSS, and asynchronous JavaScript logic with input sanitization and loading states.
* `docs/` - Comprehensive system documentation:
  * `architecture.md` - High-scale infrastructure overview and component descriptions.
  * `api-design.md` - RESTful API specifications, endpoints, success payloads, and standard error handling.
  * `data-model.md` - Relational database schema entities, relationships, and PostgreSQL DDL statements.

## Features
* Secure asynchronous API interaction with centralized request helpers and clean loading states.
* Client-side text sanitization to prevent injection vulnerabilities.
* Production-grade REST API design specifications and robust relational data modeling.
